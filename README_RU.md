# Barricade Bar

Статусбар для Wayland-композитора [niri](https://github.com/YaLTeR/niri) на Rust, GTK 3 и Layer Shell.

## Описание

Barricade Bar — это лёгкий статусбар, который отображается поверх экрана (по одному окну на каждый монитор) и резервирует под себя место. Настраивается одним YAML-файлом и CSS-файлом, оба перечитываются на лету. Приложение использует:
- **GTK 3** и **gtk-layer-shell** для отрисовки бара в Wayland-сессиях
- **niri IPC** (`niri-ipc`) для получения раскладки клавиатуры
- **wpctl** (WirePlumber / PipeWire) для получения громкости и состояния mute
- **NetworkManager** (D-Bus, через `nmrs`) для получения состояния сети
- **sysfs** (`/sys/class/power_supply`) для получения состояния батареи
- **Rust** для обеспечения производительности и безопасности памяти

## Возможности

- Три зоны (слева, по центру, справа) с любым набором и порядком виджетов
- Виджеты: `clock`, `audio`, `layout`, `network`, `battery`
- Громкость и заряд батареи плавно выезжают при наведении курсора
- Виджет батареи скрывается на устройствах без батареи
- Отдельный бар на каждом мониторе, новые мониторы подхватываются автоматически
- Необязательная команда, привязанная к виджету и запускаемая по клику (например, окно управления звуком)
- Горячая перезагрузка конфига и CSS-файла без перезапуска
- Сеть опрашивается в фоновом потоке, поэтому D-Bus не блокирует интерфейс

## Установка

### Требования

- Rust 1.85+ (edition 2024)
- GTK 3.x
- GTK Layer Shell 0.7+
- niri (виджет раскладки обращается к его IPC-сокету)
- Wayland-композитор с поддержкой `wlr-layer-shell`
- Утилиты и службы времени выполнения: `wpctl` (WirePlumber), NetworkManager
- Тема иконок со стандартными символическими иконками freedesktop (например, Adwaita)

### Сборка

```bash
git clone https://github.com/yarok-k/barricade-bar
cd barricade-bar
cargo build --release
```

### Запуск

```bash
cargo run --release
```

## Использование

Запустите бинарник из конфига niri:

```kdl
spawn-at-startup "/path/to/barricade_bar"
```

### Конфигурация

Конфиг находится в `~/.config/barricade/bar.bst` и создаётся при первом запуске. Это YAML-файл с тремя списками виджетов и необязательным путём к CSS-файлу:

```yaml
elements:
  left:
    - "layout"
  center:
    - "clock"
  right:
    - "network"
    - audio: "barricade-sound"   # команда, запускаемая по клику
    - "battery"
stylesheet: "~/.config/barricade/style.css"
```

- Элемент — это либо просто имя (`"clock"`), либо `имя: "команда"`. Значения `""`, `null` и `none` означают «без команды».
- Доступные элементы: `clock`, `audio`, `layout`, `network`, `battery`.
- Сейчас команду использует виджет `audio`.
- Относительные пути к стилю считаются от `~/.config/barricade/`, `~/` раскрывается в домашний каталог. Пустое значение означает отсутствие пользовательских стилей. Если CSS-файла нет, он создаётся пустым.
- Если в конфиге ошибка, бар остаётся прежним, а ошибка выводится в stderr.

### Стилизация

Фон бара имеет CSS-класс `barricade_background`. Остальные узлы стилизуются стандартными именами GTK 3 (`button`, `label`, `image`, `revealer`).

```css
.barricade_background {
    background: #1e1e2e;
    color: #cdd6f4;
}
```

## Структура проекта

```
src/
├── main.rs              # Точка входа, layer-shell окна, горячая перезагрузка CSS
├── ui.rs                # Раскладка бара (слева / центр / справа), периодическое обновление виджетов
├── lib/
│   ├── mod.rs           # Модули библиотеки
│   ├── audio.rs         # Громкость / mute / устройства через wpctl
│   ├── battery.rs       # Состояние батареи из /sys/class/power_supply
│   ├── layout.rs        # Раскладка клавиатуры через niri IPC
│   ├── network.rs       # Сетевые устройства через NetworkManager (nmrs)
│   ├── bluetooth.rs     # Зарезервирован, пока не реализован
│   └── core/
│       ├── parcer.rs    # Парсер конфигурационного файла
│       ├── placer.rs    # Сборка виджетов и размещение по зонам
│       ├── widget.rs    # Общий трейт виджетов
│       └── element.rs   # Обёртка собранного виджета
└── widgets/
    ├── mod.rs           # Модули виджетов
    ├── clock.rs         # Дата и время
    ├── audio.rs         # Индикатор громкости
    ├── layout.rs        # Индикатор раскладки клавиатуры
    ├── network.rs       # Индикатор сети
    └── battery.rs       # Индикатор батареи
```
